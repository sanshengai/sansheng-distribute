# 公众号已群发文章留言：官方只读候选

仅面向有对应留言接口权限的账号：微信官方的 `listComment` 适用范围为企业主体已认证账号。账号在网页上能留言或回复，不代表有此接口权限。此候选只经离线模拟，尚未通过符合资格的真实账号验收；不可用于断言个人未认证账号支持 API。区分公众号文章留言、公众号私信和微信视频号评论，这里只处理前者。

该接口要求**群发后返回的数字 `msg_data_id`** 及多图文序号，不能用草稿 ID、文章链接或猜测得到的数字代替。先由用户或可信群发回执提供真实 ID 并确认所属账号；找不到 ID 时使用平台官方后台，不能虚报此候选已覆盖该文章。已群发不是草稿。每页请求数采用 40；官方参数描述写明大于或等于 50 会被拒绝，故严格限制不超过 49。官方文档及账号审核状态可能变化，应按当前平台实际能力使用。

调用示例（在 Skill 根目录，替换占位参数；私有配置与状态目录不能放入 Git）：

```sh
python3 scripts/wechat_comment_candidate.py --profile '<private-profile>' --account '<account>' --state-dir '<absolute-private-state>' --msg-data-id '<broadcast-msg-data-id>' --index 0
```

复用公众号现有私有凭证及账号指纹绑定；不把凭证写在命令行，也不输出令牌、评论正文或用户身份。程序只读取指定的一篇已群发文章，写入私有收件箱；分页时总数变化、重复评论、响应缺字段或过早结束均标为不完整。页数默认上限 20，可显式调整；出现错误、未查完或只查询单篇，不代表该账号没有其他评论。即便所选文章返回结果已查完，公众号整体仍显示“部分覆盖”。本地记录不会因下次 API 未返回而自动删除；回复前必须核对原始评论。

接口可能返回账号已有的回复；本机只保存供后续人工核对，不将其等同于本 Skill 发出的回复，也不主动将评论标为已处理。此候选没有实现回复发送、自动扫描所有文章、平台推送或定时服务；这些须另行设计和验收。遇到账号无权限、授权/IP 白名单问题或请求失败要保留错误并停止，不凭空生成“无新留言”。
