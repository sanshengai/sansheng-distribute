# 平台交接查询

需要先了解某个平台能接收什么，以及本机配置了哪些校验时，使用：

```sh
python3 scripts/publish.py platform-guide youtube
python3 scripts/publish.py --profile /private/profile.json platform-guide douyin
```

命令读取本包支持的交接内容类型、社交平台工作单中的核对提示与所选配置里该平台的规格、适配器启用标记和能力清单。不输出账号、凭证、执行器路径或其他平台配置；未知平台、格式错误的规则和非白名单能力会拒绝查询。规格中的扩展名遵守发布包相同的类型规则；少见的扩展名以占位符显示，并用 `configured_policy_redacted` 标记，避免透出误放进配置的私密字符串。显式指定的配置文件不存在时会报错；未指定且默认配置不存在时视为空配置。

结果是本地只读快照：内容类型代表交接格式，不代表自动发送能力；启用标记代表配置，不证明平台当前可用或真实验收。`enabled` 只用于配置与诊断，并非执行器总闸；执行还要检查账号、具体能力、授权、验收范围及适配器。YouTube 列出本包目前校验的必要受众与可见性字段，实际平台规则仍须核对。没有连接平台、登录、创建账本或授权。平台当下规格、账号权限与真实发送能力仍以原生平台和[平台能力与证据](platforms.md)为准。稿件的实际素材和平台字段仍用 `pack` 和 `batch-preflight` 校验；本查询不会检验素材或生成发布包。
