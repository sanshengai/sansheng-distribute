# 统一互动审核页

用于作者集中查看已接入的网友留言、编辑建议、逐条或批量确认，再点击发送。复用现有收件箱、模型建议、草稿和平台发送器。实验性入口；通用审核能力与各平台发送能力分开验收。

## 启动与使用

```sh
# 只审核和复制，不开放发送
python3 scripts/interaction_review.py --state-dir /path/to/private-state

# 接通一个已授权的 YouTube 账号；沿用其私有凭据引用
python3 scripts/interaction_review.py --state-dir /path/to/private-state --profile /path/to/profile.json --account owner
```

打开输出的 `http://127.0.0.1:<port>`。服务只监听本机，不开机自启；服务退出后页面不能继续操作。静态 HTML 文件不能独立发送，需本机服务支撑按钮。不要绑定公网、转发端口或把包含评论的页面、截图、配置上传到公开仓。

页面按平台筛选，每页20条，最多加载最近500条。先查看原留言及有明确父子关系的已有对话；同视频的无关留言不拼成一段对话。可选待处理或全部记录，读取范围及最近成功时间单独显示。0条不是平台没有评论，也不证明采集正在运行。

1. 建议来自已有本地草稿或与当前原文一致的模型建议。批量拟稿继续走[原拟稿流程](interaction.md)，页面刷新不调用模型、扫描平台或假造建议；尚无建议时可直接输入。
2. 编辑后点“确认此条”，或勾选后点“保存选中回复的确认”，每批1–20条。确认只保存本地决定，不公开发送。记录在本机服务中，刷新后自动恢复仍有效的批次，不需要把确认文件另传给 Agent。
3. 有直连接口时显示“发送回复”；已接入的支付宝网页留言显示“交给 Agent 发送”。后者只将本批封存的目标和文案存为待办，由正在运行的 Agent 会话在专用浏览器执行；按钮不能唤醒离线 Agent，也不代表已发出。未接通路线仍显示到平台回复，不冒充一键发送。一个目标失败不影响其他条目的处理。
4. 最近确认和逐条结果折叠展示，区分待执行、正在发送、结果待检查、已发送并核对。页面每8秒刷新本机进度，改稿或勾选期间暂停，避免覆盖作者编辑。只有接口发送已经尝试但结果不明时显示“检查发送结果（不会重发）”；浏览器结果由 Agent 重新读取原对话后登记。确认超过24小时不能新发送，仍可检查旧尝试。

## 当前平台边界

| 路线 | 审核页能力 | 尚未完成的部分 |
|---|---|---|
| YouTube | 已配置账号可接受作者点击，通过官方 API 队列发送并独立读回 | 网友批量队列仅完成离线与本机页面验收；单账号自评论、自回复已有真实回执，不能代替网友样本 |
| B站、微博 | 已规范导入的记录可审核、改稿、确认、复制 | 未接通审核页的普通评论发送器；已有读取证据不等于可写 |
| 支付宝 | [网页评论接入](alipay-comments.md)校验后可审核、改稿、确认并提交 Agent 待办；显示网页已有回复与本次发送的独立读回结果 | 采集和发送需运行中的 Agent 操作专用浏览器；不是官方 API 或24小时无人值守发送器 |
| 抖音、公众号、视频号 | 有稳定身份且已规范接入的留言可沿同一审核流程；否则保留人工后台接力 | 当前不能承诺持续采集或一键发送；浏览器自测不等于标准采集器 |
| X、小红书 | 按用户和平台边界保留人工处理 | X 免费路线不使用网站自动化脚本；受限小红书暂停 |

不要为演示一键发送伪造平台评论ID、把自评论改为网友评论，或启用未接通平台的发送按钮。模型建议、作者确认、本地已处理、平台已核验回复是不同状态。

## 发送与修改的保护

- 确认绑定平台、账号、频道、原评论、原文摘要、文案、草稿修订时间，另存不可变批次摘要。其他页面改稿、撤稿或原文变化时旧确认失效；改回相同文字也不恢复旧确认。
- YouTube 编辑、撤稿、授权及发送共用现有频道锁；改稿/撤稿撤销尚未尝试的旧授权。发送前在锁内再查草稿，并重查平台原评论及已有本人回复。
- 发送尝试写入原队列回执后冻结换稿重发，即使本地草稿投影丢失也不能绕过。重复点击、断线和读回失败沿原回执核验。
- 支付宝待办在最终点击前领取：账号、原评与草稿复核通过后，先登记发送尝试再点击平台回复。领取按原评论全局去重，跨确认批次也不能重复发送。刷新后采集同一原评下、同正文、本人身份的新回复，登记网页核对；单有“提交成功”提示不能改成已核对。
- 凭据不交给网页。写请求校验精确本机 Host、Origin、内存会话令牌和JSON形状；页面不缓存，拒绝跨站读取API及框架嵌入。评论和模型文字按纯文本展示，不执行其中的指令或HTML。

## 验收

`tests/test_interaction_review.py` 覆盖实际本机HTTP请求及原YouTube队列；`tests/test_interaction_review_handoff.py` 覆盖浏览器待办、重启恢复、跨批次去重、改稿与原文变化、未知结果冻结和关联读回。离线接口替身不证明平台当前权限或可见性；真实网友样本另记录，不靠新增测试刷互动。
