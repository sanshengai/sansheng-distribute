# 支付宝生活号视频：Agent 接力指引

这里是**通用 Agent 浏览器接力的待验收指引**，不是本包内置的支付宝自动上传器或状态读取 API。已有本地视频交接、工作单与通用接力合同；具体账号、浏览器通道、原生字段与独立读回仍要逐项验收。不能将“工作单生成”“登录成功”“上传完成”当作已发布。

## 接力前

1. 生产端交付定稿、视频、指定封面、标题和描述；`platform_metadata` 中作者明确的 `collection_name`、`ai_generated` 等必须保留。通过 `seal`、`check`、`pack` 和 `preflight` 检查文件、目标及既有授权；未被启用/验收的能力不自行打开。章节与通用配置见 [交接](handoff.md)、[社交平台接力](social-adapters.md) 和 [首次验收](acceptance.md)。
2. 用宿主许可的专用 Chrome，默认后台；在生活号创作后台观察生活号名称和**平台显示的生活号 ID**，与私有 profile 对该目标绑定的 `public_identities.alipay` 核对。名称、本地 account 别名、cookie 存在或成功打开创作页不能替代平台 ID；不一致、无法观察或需要扫码时停下。平台身份和凭据只存私有环境。
   扫码后若进入身份选择、生活号选择或空白入驻表单，先等待该页正常加载，核对已有个人/运营身份及生活号列表；短暂的“还没有生活号”不能据此判定账号不存在或重新开通。优先选择已有身份，随后以显示的生活号 ID 确认登录恢复，不因中间空态要求作者重复扫码。
3. 按约定终点和已有授权启动持锁接力；通过 `social_adapter.py inspect --request ...` 检查当前有效阶段、任务和发布包。每次远端写入之前重新确认该阶段仍有效，不能在接力超时后继续操作。

## 当前界面上的预填与提交

进入支付宝内容创作平台，使用当前可见的“发布视频”入口，选择交接的视频；若当前界面与指引不同，以真实界面为准，不盲点旧坐标。等待平台完成上传和处理，利用处理时间填写标题、描述和适用话题；不按旧经验假定字符数上限，也不静默截断内容。话题文字是否转换为原生话题要分别核对。

- **封面**：上传作者指定的图片，检查平台实际要求的比例和裁切预览。裁切导致标题、主体或关键信息被遮挡时调整裁切并复核；无法保留作者要求就停下说明，不把原图哈希当作平台裁切图已核验。
- **合集**：按作者明确给出的合集名称查找并选择，确认选中结果；找不到、多个同名且无法辨认或保存后未能确认时停下，不能跳过后声称已归集。
- **AI 与原创声明**：按作品事实和平台当前字段填写；`ai_generated` 未提供时表示未知，不自动选择“否”。独立检查 AI 标注和原创/来源声明；平台不支持某字段或无法判断时保留未确认，不代作者猜测。
- **其他内容**：逐项核对标题、完整描述、话题、素材和作者指定字段；平台无法承接的字段须向作者说明，不能只因视频已上传就忽略其他交接内容。

若约定终点为预填/草稿，须有平台提供的真实可恢复身份，才能在独立读回后标注对应就绪；当前临时编辑页没有可恢复身份时仅报告现场或本地工作单，不伪造草稿。若约定为公开发布，只有在已有明确授权、上传处理完成、上述要求全部落实、账号和接力仍有效时才点击一次。页面卡顿或未观察到网络信号不能证明未提交，不再次点击。

## 投稿后独立查询

执行阶段只记录 `pending` 和可见的真实远端身份；随后在新的核验阶段，从同一生活号的内容管理页或平台提供的真实作品详情重新观察。优先使用平台实际提供的稳定作品 ID 和可恢复链接，核对同一账号、作品、内容、封面、合集与声明；可播放性、审核与可见状态分别记录。不可用本地任务键、列表标题加时间、临时编辑页或自行拼出的 URL 冒充作品 ID。当前尚无经过本包验证的支付宝作品 ID 获取与原片身份绑定方式；若当前页面无法建立这些证据，保留待核验/未知，勿宣称完整读回。

- 页面显示**审核中或已提交审核**：记录 pending，不说已发布。
- 平台明确显示**已发布**：记录有证据的发布观察；推荐受限与否单独查看，不能从“已发布”推断推荐正常。
- 若平台明确提示**限制推荐**、审核不通过或其他限制，分别记录原文与观察时间；无法确定原因时标记原因未知，不自行归因或保证免风控。
- 若请求、页面跳转或回执中断，结果不明：保持原任务，按 [恢复](recovery.md) 只读核验；分页缺项或标题未出现不证明未提交，不重复上传/发布，也不以新任务绕过锁。

每阶段通过通用接力记录实际观察证据，verify 必须是新阶段；工作单摘要和素材清单是接力合同，不能代替真实页面证据。状态、身份和素材观察记录仅保存在私有环境。若仅有人工作品列表观察、缺少稳定 ID，则可在系列看板作为带来源和日期的外部观察，不写成自动适配器已验收的正式账本结果。

## 研究线索和边界

对 [Social Auto Upload 固定版本的支付宝上传器](https://github.com/dreammis/social-auto-upload/blob/3847fff01f5434a8a32829833163cd6723cabc59/uploader/alipay_uploader/main.py)仅作页面流程线索：该版本仅以页面或登录框判断会话，未在上述流程绑定生活号 ID；指定封面、合集或 AI 声明失败可能只警告；未观察到提交信号时可能再次点击，且将“提交审核”当成功。这些行为不能作为本 Skill 的成功条件，不直接调用其自动投稿器。页面和平台规则可能变化，必须现场重核。
