# 视频标题、简介与话题

适用于已有定稿的视频分发；在封存清单之前读取。平台有不同字段和表达习惯，不把一份文案复制到所有平台，也不靠运营口诀推断推荐算法。研究基线：2026-10-24；硬限制仍以当前账号实际投稿入口为准。

## 从成片到平台文案

准备视频文案时，如存在私有文件 `~/.config/sansheng-distribute/preferences.json`，读取其中 `video_caption` 偏好；这是作者私有配置，不进公开仓。文件缺失则按当前任务授权与通用规则处理，不创建或改写账号 profile。

1. 首次进入某平台或换入口，先只读检查字段、字数、允许符号、合集与声明选项，再准备和封存文案；不要先上传或启动执行后才发现短标题不合法。
2. 读取本集成片或权威剧本，核对人物、事件、台词与实际收益。每集提炼一个具体场景或冲突，禁止虚构剧情、教学效果、制作方式或时长承诺。
3. 分别准备标题、描述、标签/话题、封面叙述及系列/集号。标题与封面互补；系列识别保持稳定，逐集钩子有变化。学习内容同时照顾故事吸引力和准确学习点，不写成关键词堆积。
4. 标签候选覆盖内容类别、具体场景/知识点、系列；少而相关，不凑满上限、不蹭无关热榜。标签候选不是已绑定的话题。
5. 将各平台独立文案写入对应 target，再 seal。实际界面需要改文案或字段时，先更新交接包、重封存并核对已有授权范围，不能执行中静默改稿。

## 各平台映射

| 平台 | 标题与正文 | 标签/话题与现场确认 |
| --- | --- | --- |
| B站 | 系列作品先遵循作者确认的总分结构：系列名、季集编号、本集标题；单条作品可把具体场景/冲突放在前面。简介交代剧情、实际价值、观看方式。内容分类与自制/转载声明按真实制作来源。 | 标题、简介、投稿标签、原生话题分开处理；标签填专用区。简介中的 `#词` 不代替投稿标签或原生话题；话题须通过选择器实际选中。 |
| 抖音 | 系列的独立短标题沿用已确认的系列名、季集编号、本集标题；描述第一句给具体钩子，接一句真实收益；若当前入口另有短标题，单独填写。不能假设所有入口都有同一套标题/简介字段。 | 话题通过原生选择器确认；保留有意义的完整叙述，不只留标签。不能无差别粘贴 `composed_text` 而丢失独立字段。 |
| 微信视频号 `wechat_channels` | 使用视频号助手；2026-10-24网页实测短标题最多16字且限制特殊符号（竖线不能直接沿用），限制以当前页面为准；完整标题保留在描述首行，必要时在封存前通过 `platform_metadata.short_title` 明确短标题，保留系列及集号，不能执行中临时截断。独立短标题按系列规则填写，完整描述说明本集场景与价值。公众号、视频号和腾讯视频是三个不同目标。 | 原生话题、短标题、封面比例、原创/AI声明及合集按当前页面逐项确认；未绑定的井号文本不登记为原生话题。 |
| 腾讯视频 | 标题便于剧集查找，简介简洁说明剧情与实际价值；是否可建专辑/合集以当前账号权限为准。 | 进入腾讯视频创作平台，不套用微信视频号或企鹅号规则。若无原生话题字段，保留相关标签建议，不机械粘贴井号串或声称绑定话题。 |
| 小红书 | 独立标题和正文：一个具体使用场景与能获得的体验，正文可给少量实际例句、观看方式。避免空泛效果承诺。 | 原生话题选中后回读。受限账号只准备本地包；其他账号最后点击仍由作者完成。 |

上述是编辑建议，不承诺流量。不要把“某博主用了”当作“效果很好”的证据；参考样例应记录它展示的写法与适用场景，表现数据不可得时明确写未验证。

## 系列发布、合集与发布后更正

系列作品在封存前确认一套命名模板，例如 `「系列名」S1E01｜本集标题`：系列识别在前，季集编号补零，本集标题在后；分集钩子放在简介开头。作者确认的命名优先于泛化的平台运营建议，不把某个作者的偏好变成所有账号的硬要求。相同系列在不同平台保持同一身份与集号；字符限制发生冲突时调整方案后再封存，不静默截掉系列名或改集号。

发布前按集号逐项核对成片、横竖版、标题、简介、封面和目标账号。封面保持系列识别，同时用本集画面或文字区分，不以后台列表的临时缩略图代替实际封面。标签与原生话题分开核验；原创、AI生成、转载等声明依实际来源填写。

合集使用作者确认的名称与面向观众的简介：说明讲什么、适合谁、如何观看，支持时可分段并使用少量 emoji。保存后重开核对；平台去掉换行时如实记录，不声称排版已保留。合集权限不足可按已有授权逐集发布，实际账号、合集ID、路由和特定作者的命名模板只放私有配置与任务记录，公开 Skill 不保留这些值。私有路由文件尚未被执行器消费时，仍须逐项操作核对，不能声称已自动归集。

已发布作品需要更名时，先从管理列表按真实作品ID定位，核对当前标题及平台可修改次数；沿用原作品的编辑入口，禁止通过删除重发来实现。保留更正计划、原ID和独立读回证据，核对简介、话题、封面、可见性、合集归属及顺序未意外改变。视频号2026-10-24发布后编辑页提示描述/短标题仅支持修改20个字，不能假设可无限改稿，执行前先核对当前限制。原封存清单保留为原始快照，更正另记，不改旧快照、不拿旧标题重新投稿。核心未提供编辑命令时，明确由当前 Agent 操作原生编辑器，不能把人工接力冒充 API 能力。修改后若重新审核，维持 pending，待真实可见再报告 published。

## 投稿时补齐的证据

记录 `observed_at`、`entry_url`、`account_scope`，以及界面字段名称、字数计数/提示、文件限制、原生标签或话题选中名称。保存在任务证据中，不新增未经实现的 profile 配置键。当前 `platform_policies` 的长度检查按 Python Unicode 码点计数；须区别于平台实际计数。旧 API、其他发布入口与网页规则分别记录，不硬套永久上限。

提交前回读实际标题、简介、标签/话题实体与封面；保存后独立重开核对。只有文字中出现井号，不能登记原生话题已选中。原生选择器没有所需候选时记录缺失，不擅自替换为无关话题。平台要求原创、AI生成或其他内容声明时，按真实制作来源填写；不确定的关键声明先查生产端证据。

B站部分词属于保留话题，直接按回车不能创建普通标签；出现该提示时，改用原生话题搜索选中同名候选，并回读标签实体。封面需等待编辑器完成保存；要求同步比例时，确认同步后仍须完成封面编辑。抖音需等待封面检测和视频上传完成，再核对竖横封面、原生话题、AI声明及合集。

合集权限不足时，按用户授权先逐集投稿；不让创建合集成为投稿的隐含前置条件。账号与合集的真实对应关系保存在用户私有配置和任务证据中，不能写入公开 Skill。

上传、提交、审核中、公开可看分别记状态。已有目标的账号、素材、封面、文案和集号一一对应；批量完成率不能掩盖单集失败或错配。

## 活动、热门话题与真实声明

用户授权自动选择活动时，从当前平台推荐或活动搜索中筛选与成片内容、参与条件相符的活动。记录实际活动名、适用条件及已选状态；不相关、资格不符或有额外承诺的活动不勉强参加。没有相关候选就记录未参加，不把入口存在当成已参加。

话题兼顾覆盖面与相关性：先检索平台当前候选、推荐及可见热度，再选内容领域、具体场景和系列词。没有热度数据时称相关或覆盖面较广，不声称热门，更不保证流量。通过原生选择器或编辑器实际生成的话题实体添加，再独立核对；纯井号文本和已绑定实体分开记录。

原创与AI标注是两个不同问题。自有作品满足平台原创条件时可按用户授权声明原创；如果平台对AI作品另有限制，先读当前条款。视频内标识、平台原生声明与配文是不同位置：按内容实际情况及当前平台要求如实使用原生声明；是否在配文额外说明，按用户偏好和平台要求判断，不因使用AI就自动重复添加文字。不能因勾选原创而省略适用的AI声明，也不能假定视频已有标识就满足平台全部要求。转载、授权和其他声明依据生产端来源，未知时不勾选。相关界面新增声明时及时补齐交接记录，不靠固定旧选择器猜测。原创声明审核和作品公开状态分别记录；已勾选不等于原创审核通过。若发布后入口未暴露某声明字段，保留提交前的实证并明确读回边界，不假称已重开核对。

视频号原创条件参照当前编辑器链接的 [原创声明及相关功能使用须知](https://support.weixin.qq.com/cgi-bin/mmsupportacctnodeweb-bin/pages/s6zCQ8q4oR2FpRXe)；该须知不等于其他平台规则。

2026-10-27 视频号助手实测短标题拒绝感叹号，问号可接受；完整标题与短标题分别核对，必要时只为短标题准备合规版本，在封存前确定，不改变正文首行的完整标题。符号规则仍以当前页面校验为准。

视频号网页当前支持个人主页和分享卡片3:4封面；横图上传会裁切，须检查人物、字标及标题是否保全，不把上传成功当成封面验收。合集创建入口与简介字段也按当前账号实际界面处理，不捏造不存在的简介。

## 每次分发的复盘

每次分发收尾必做，执行 [分发复盘](retrospective.md)，不能把它作为可选建议。收尾核对每个目标的真实ID、文案、封面、话题、活动、声明、合集、审核及可见状态，区分已提交和已公开。总结本次新增的可复用经验：规则变更、真实字段限制、失败根因与有效修法。修改本 Skill 的对应 reference 并按版本规则验证、同步；普通操作笔误不制造规则，未经验证的推测标为待验，不写成平台事实。账号身份、合集路由、作品ID及唯一证据进私有任务记录；共享故障只有达到踩坑库收录标准才另入库。不重复上传试错，不直接改账本解锁未知任务。
