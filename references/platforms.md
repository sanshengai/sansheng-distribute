# 平台能力与证据

实验版。实现覆盖与真实平台验收分开记录。

| 平台 | 已实现路径 | 真实平台证据与边界 |
|---|---|---|
| 公众号 | HTML 草稿 API、原生媒体槽、编辑器补齐、官方读回 | 一个真实账号测试草稿已通过建稿、音视频插入、保存重开、播放、手机宽度预览与全文读回；发表/群发及正式 Write 回导未验收 |
| X | 平台包、Agent 执行/独立核验、可选宝玉锁版本预填桥 | 新统一入口未做真实账号验收；桥仅预填，不公开发送 |
| 微博 | 平台包、Agent 执行/独立核验 | 新统一入口未做真实账号验收 |
| 抖音 | 视频包、Agent 创作后台执行/独立核验 | 一个真实账号已完成8集竖版投稿、原生话题与AI声明、封面、合集及顺序读回；发布后按原作品ID更正标题并独立核验。其他账号权限仍须实测 |
| 微信视频号 | 独立 `wechat_channels` 视频包、Agent 浏览器接力与独立读回 | 一个真实账号已验证竖版投稿、独立短标题与描述、原生话题、3:4封面、合集、相关活动及原创申请；素材MD5与原片一致，取得原生分享链接并独立读回。AI标注在提交前核对，发布后编辑入口未暴露该字段；原创审核另记，不能使用公众号或腾讯视频能力代替 |
| 腾讯视频 | 独立腾讯视频工作单、Agent 执行/独立核验 | 未做真实账号验收；不是视频号，不使用 SAU tencent 冒充 |
| B站 | 视频包、Agent 创作后台执行/独立核验；可选受控CLI适配器 | 一个真实账号已完成8集横版网页投稿及独立读回，后按原作品ID更正标题；另有单条CLI试验受理/公开读回证据。新通用CLI适配器已有离线合同和真实只读验证，尚未真实上传验收，默认关闭。旧账号合集权限不足不代表全部账号 |
| 小红书 | 图文/视频包及预填工作单 | 未做真实账号验收；作者最终点击，受限账号只准备本地包 |

这些社交适配器依赖当前 Agent 的实际浏览器工具，不是无人值守的站点上传 SDK。真实账户、界面行为、可恢复远端身份与独立读回仍须逐项验证。未验证能力默认关闭；精确的首次草稿试验按 [验收方法](acceptance.md) 执行。

核心离线验证覆盖授权、素材遗漏、账号锁、未知恢复、批量部分失败与平台包完整性；离线测试不能代替平台证据。Write 旧稿认领与回传已有离线合同测试，真实正式文章收尾仍须验收，不能同时开启两个上传写入者。

上游来源及完整提交见 [来源锁](sources.json)。宝玉采用 MIT；social-auto-upload 仅作候选研究，不捆绑或默认启用。README 能力表不证明用户自己的账号可用。
