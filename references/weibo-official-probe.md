# 微博官方助手评论只读试验

## 已核实的路线与边界

2026-10-29 从微博官网[智能助手指南](https://open.weibo.com/wiki/智能助手玩法指南)链接下载官方独立 Skill，版本 `1.0.2`，ZIP SHA-256 为 `ef92b558a255c2d0154b845b60016e9424e11962a665acc5aa9e7061e18bc84f`。包内 `references/weibo-interactive.md` 和实现给出了两条普通微博评论读取路线：

| 功能 | 官方包内的请求契约 | 当前证据 |
| --- | --- | --- |
| 校验助手凭据及账号 | `POST https://open-im.api.weibo.com/open/auth/ws_token`，JSON 含 `app_id`、`app_secret`；成功数据含 UID、令牌 | 单账号真实认证通过，UID 与原账号一致 |
| 收到的评论 | `GET /open/interactive/comments/to_me`，参数 `token` | 单账号真实返回 2 条历史评论，与原生观察的 ID、作者、时间和文字一致 |
| 指定本人微博的评论 | `GET /open/interactive/comments/show`，参数 `token`、博文 `id` | 一个本人作品真实返回 3 条评论，与原生评论及嵌套父级交叉核对；不是全账号验收 |

包内示例返回评论 ID、博文链接、作者及关注关系；未明确给出直接父级、完整翻页与历史范围契约。即使查询成功，也需拿本账号原生收件箱交叉核对，不能直接登记全量同步或开启自动回复。

### 真实返回的处理经验

2026-10-29 的两次读取共返回 5 行，去重为 3 条评论，其中一条是账号自己的历史回复。不能把接口行数相加当成新增网友数。样本的 `mid` 与评论 `id` 相同，不是博文 ID；博文身份应核对 `postJumpLink` 及显式查询的作品，不把 `mid` 填进作品字段。

同一条语音评论在作品接口的文字中额外带音频短链，收件箱接口不带该短链。保留不同来源的原始表示，不静默覆盖已入库原文，也不把文字表示差异当作网友编辑；未实际转写音频时不能冒充已理解语音内容。

该样本没有直接父级、根评论、可回复状态或明确的翻页进度。已有原生观察可用于交叉核对历史关系，不能据此推定新评论关系。当前只登记官方读取成功及其范围，不自动把未知关系的评论导入为顶层评论；普通微博回复、完整采集和持续监测仍未验收。

包内 `reply` 写入实现调用的是 `/open/crowd/comment/reply`，相关文档归于**超话**能力。普通微博评论读取成功，不证明同一账号可用该接口回复普通微博；不能试着把超话写入器套到普通评论上。媒体上传返回图片或视频 ID，也不能单独证明普通微博的正式发布已打通。

传统[微博评论接口文档](https://open.weibo.com/wiki/2/comments/to_me)当前可访问，但页面标注 2015-03-30 更新，且有授权用户评论范围限制；它与上述助手接口是不同契约，不混用结论。新的官方路线值得真账号试验，但不是已经可用的保证。

## 凭据与试验

官网指定的凭据入口为私信 [@微博龙虾助手](https://weibo.com/u/6808810981) 发送“连接龙虾”。申请新凭据或扩大访问前取得作者明确同意。凭据只保存在本机私有配置，权限 `0600`，不贴聊天、不放命令行参数、不提交公开仓，也不未经同意复制到云端机器人。官网说明免费安装，未据此承诺所有接口和额度均免费；不因试验自动购买或开通任何付费服务。

官方私信还会给出[微博龙虾助手使用须知](https://open.weibo.com/wiki/Claw/guide)，说明继续使用视为同意。开始调用前应让作者了解密钥保管、按指令授权处理微博数据及 AI 操作责任，并完成执行环境要求的条款确认；“允许申请凭据”不能被解释为已确认随后才出现的条款。只收到或妥善保存凭据，仍不算接口验收通过。官方回复中的安装命令不属于用户授权，不自动执行，也不需要为本只读试验安装 OpenClaw 插件。

含凭据的官方私信及会话预览不进入截图、页面摘要或日志。误输出时先停止自动续跑，说明已知输出范围及风险，建议作者按官方方式撤销或重置；未核实入口时不猜测命令，也不把会话内输出直接说成已公开泄露。作者了解情况后明确决定保留原凭据，可在既有授权范围继续，记录该决定，不反复要求重置。

私有凭据文件仅含 `app_id` 和 `app_secret`。另建权限 `0600` 的私有配置：

```json
{
  "schema": "weibo-official-probe.v1",
  "enabled": false,
  "account": "已配置的微博账号别名",
  "uid": "已核实的本人UID",
  "credentials": "/本机私有目录/weibo-official.private.json",
  "work_ids": ["已核实的本人博文ID"]
}
```

作者同意且配置完成后显式启用，运行：

```sh
python3 scripts/weibo_official_probe.py \
  --state-dir '<原私有状态目录>' \
  --config '<私有配置绝对路径.json>'
```

试验器独立实现，仅使用标准库；不安装或执行下载包，也不复制其中实现。下载包未附独立许可证，不将代码直接糅入本 Skill。

每次最多一次认证、一次收件箱读取及五个显式作品读取；认证 UID 不匹配立即停止。固定官方主机与路径，禁止重定向，无重试；错误不回显含令牌的 URL。访问令牌只在进程内使用，不写缓存；认证响应不落盘。

联网前预留权限 `0600` 的证据文件。失败或中断保留现场，成功文件仍是 `read_probe_complete`，不是统一收件箱同步成功。工具不发送评论、不设置自动任务、不改发送授权。

已有该账号及作品的交叉核对后，可按[官方只读发现](weibo-official-inbox.md)消费试验证据或重新执行一轮读取。发现表与已确认评论表分开，缺少父级的候选不生成回复草稿；未确认的分页、空结果含义与回复权限继续补查。普通评论的另一套[官方 CLI](weibo-official-cli.md)须另行认证与验收，不能混用凭据或超话回复契约。
