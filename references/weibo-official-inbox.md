# 微博官方只读发现

用于已获授权的[官方助手读取](weibo-official-probe.md)。单账号已完成真实认证、两个接口读取及原生记录交叉核对；默认按需执行一轮发现，需要持续观察时显式指定有限轮数。普通评论的另一套官方 CLI 路线见[接入评估](weibo-official-cli.md)，不能复用这里的凭据推断可发送。

## 配置与执行

配置放在仓外私有目录，权限 `0600`；状态目录权限 `0700`，沿用同一互动账本。示例中的 UID、作品及路径须来自已核验的实际配置：

```json
{
  "schema": "weibo-official-inbox.v1",
  "enabled": true,
  "account": "已配置的账号别名",
  "uid": "已核验的数字UID",
  "credentials": "/本机私有目录/weibo-official.private.json",
  "work_ids": ["已核验的本人博文数字ID"],
  "not_before": "2026-01-01T00:00:00+00:00"
}
```

`not_before` 使用该账号原有监测起点；示例日期不是推荐起点。首次绑定后，账号别名、UID 和起点不能改绑，不能靠换别名或调整日期把旧评论重新当作新互动。`enabled` 必须显式为真；这只是本地开关，不代替用户的实际读取授权。

```sh
python3 scripts/weibo_official_inbox.py --state-dir '<私有状态目录>' --config '<0600的配置.json>' sync
python3 scripts/interaction_dashboard.py --state-dir '<同一状态目录>' --output '<新的私有看板.html>' --platform weibo
```

已有原始试验证据时可离线接入，不重复调用平台：

```sh
python3 scripts/weibo_official_inbox.py --state-dir '<私有状态目录>' --config '<0600的配置.json>' ingest --evidence '<原始私有试验证据.json>'
```

## 状态含义

- 先认证 UID，再查询“收到的评论”和配置中的本人作品。单轮不自动翻页或重试；同一状态目录、同 UID 的并行读取会被拒绝。
- 两个接口的同一评论按稳定 ID 去重；作品、作者或时间冲突整轮拒绝。`mid` 在真实样本中是评论 ID，不能当作作品 ID；作品由核验后的本人博文链接确定。
- 同一语音评论在不同接口可能带不同短链或文字表示，各自保留，不覆盖已确认原文。接口缺少根评论、直接父级及回复状态时，不猜成顶层留言。
- 结果存入独立发现表；不直接写入已确认评论表，不生成草稿、不发送。历史留言、自评论分别计数；近期外部候选显示为“待补上下文”，须补齐原生关系后才能按[观察接入](weibo-comments-capture.md)进入回复流程。待补数量不等于新增真人数量，作者身份仍需判断。
- 成功也保持 `partial`：没有完整分页、父子关系或全账号覆盖证据。空列表不代表没有评论。失败显示 `error` 并保留旧记录及上次成功时间；中断可能留下 `running`，不得解释为本轮完成。

看板默认不含评论正文；`--include-text` 才把待补候选各接口的文字放入私有折叠区。相同账号的人工历史观察与官方发现合并展示，但来源和范围仍区分。原始证据在状态目录的 `weibo-official-probes/`，不得放入公开仓或未经授权同步到云端。

本轮真实样本：两个接口返回 5 行、3 条不同评论；重新读取新增 0 条，2 条历史留言、1 条自评论，未增加草稿或发送。该结果不证明普通评论回复、持续监测或所有账号已验收。

## 有限轮次观察

沿用相同的配置和状态目录，不扩大账号或作品范围：

```sh
python3 scripts/interaction_weibo_watch.py --state-dir '<私有状态目录>' --config '<0600的配置.json>' watch --cycles 3 --interval-seconds 1800
python3 scripts/interaction_weibo_watch.py --state-dir '<同一状态目录>' --config '<同一配置.json>' status
```

默认一轮；可显式指定 1–49 轮，间隔 1800–86400 秒。每轮认证 UID 并重复有界读取，仍全部记作 `partial`，不能因轮数完成就叫全量查完。不同接口重复结果不重复新增，缺少父级的候选仍不进入拟稿或发送，也不调用官方 CLI。

整段观察按真实 UID 持同机锁，换账号别名不能启动第二份。每轮检查配置：停用会停止，账号、UID、作品、凭据路径或历史起点变化也会停止；失败立即结束，不自动重试。状态可以在配置停用后查询，且不读取凭据内容。中断与超时继续保留已发现内容和运行证据。

看板会只读检查已存在的运行记录及本机锁，区分等待下轮、检查超时、意外停止和有限观察结束；不创建锁文件或自动重启。页面仍是生成时快照，运行与覆盖、发送资格分开判断。此命令不安装常驻系统任务，不能据进程启动声称已经满 24 小时或完成云端接管。
