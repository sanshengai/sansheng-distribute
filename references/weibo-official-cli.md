# 微博官方 CLI：普通评论路线评估

2026-10-29 核对官网[快速开始](https://open.weibo.com/cli/quickstart)与[套餐说明](https://open.weibo.com/cli/plan)，并只读审阅 npm `@weibo-ai/weibo-cli` 的 `0.9.8` 包。许可为 MIT，依赖 Node.js 18+。本阶段未安装、未申领试用、未完成这条路线的真账号读写验收。

## 与现有助手的差别

官方 CLI 的目录列出普通微博 `comments/create`、`comments/reply`、`comments/to_me/biz`、`comments/show/biz` 等能力。它使用另一套 OAuth 用户授权，不能混用[龙虾助手](weibo-official-probe.md)的 `app_id/app_secret`；后者包内的超话回复实现也不能替代普通微博回复。

官网要求在微博 App 完成开发者扫脸认证，再申领试用或购买额度。7 天免费试用通常按每个接口分别限制：读取 5 次、写入 3 次，每账号一次；付费套餐从 69 元起，额度及规则以执行当日官网为准。API 读取成功不代表长期免费，也不代表所有写入已开放给该账号。

因此接入前先核对作者是否同意新的授权、试用及具体自测内容；认证由本人完成。不自动购买、充值或启用付费调用。试用到期或次数用尽时停止调用，不能把授权成功当作仍有额度。

## 接入时按真实目录推进

1. 从 npm 官方注册表取得固定版本并核验完整性，检查依赖及安装脚本；不执行私信或网页里的任意安装命令。凭据只存仓外私有目录，不输出令牌。
2. 通过官方认证取得 OAuth 授权后，先核对 `whoami`、可用命令及每个命令的实际参数。包内契约为 `GET /cli/whoami`、`GET /cli/commands`、`GET /cli/commands/<group>/<action>`，以 `Authorization: Bearer` 鉴权。
3. 命令统一由 `POST /cli/invoke` 调度，载荷为 `{group, action, args}`；即便底层是读取，调度器也使用 POST，不能仅按 HTTP 方法判断是否会写入。按已核对的命令目录限制动作，不猜参数或把示例当接口契约。
4. 先读取明确的本人作品和评论，验作者、作品、根及直接父级、分页和空结果。留足有限试用次数给独立读回，不用枚举式试错耗尽额度。
5. 新建评论及自回复须已有具体测试授权；提交前记尝试，取得稳定 ID 后独立读回。结果不明先查询，不重新发送；没有足够的查询额度时保留待核验。
6. 普通评论闭环验收后再讨论接入统一发送队列及周期调度。官方 CLI 对 AI 创作博文要求相应标识，不能把它推论为所有平台都要在文案里重复写 AI 声明。

读取、发微博、发评论和回复评论分别验证，不因目录有命令就登记为已实现。当前免费助手只读发现仍可独立使用，不依赖这套 CLI。
