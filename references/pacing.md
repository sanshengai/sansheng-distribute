# 可选的平台与账号间隔

如果用户在自身使用中确认需要控制发布节奏，可在私有 profile 配置 `pacing`。它只是本机发起写入的最小时间间隔，不是平台官方限额，不保证降低风控或避免封禁；默认不设置、不推测数字。

```json
{
  "pacing": {
    "example_platform": {"platform_seconds": 60, "account_seconds": 120}
  }
}
```

把 `example_platform` 换成实际平台标识。`platform_seconds` 对同一账本的该平台所有账号生效，`account_seconds` 对同一平台的同一账号生效；可任选一项。值为 1--86400 的整数。示例数值仅用于说明格式，不是推荐频率或平台规则。不要把账号凭据写进此配置。

执行器在尝试远端写入前、与任务进入“提交结果未知”同一个 SQLite 事务中预留时间窗口；多个进程共用同一账本时也一致。已有窗口未到期时，即使切换或删除当前配置也会拒绝本次执行并保留原任务状态，不睡眠、不自动重试；已有未知提交仍必须先只读核验，间隔到期并不代表可以重发。只读查询不占用窗口。不同账本不会共享限额；系统时钟必须准确。它限制的是发起时间，不保证不同账号的长时间上传互不重叠，也不自动解析平台限流响应或设置冷却期。账号收到验证、限制或平台明确频率提示时停止并遵循平台要求。
