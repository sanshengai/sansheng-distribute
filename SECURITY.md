# Security

Please report security issues privately to **sandypoli@gmail.com**. Include the affected version, a minimal reproduction using synthetic data, and the expected impact. Do not open a public issue containing secrets or unpublished content.

Never submit platform cookies, browser profiles, API credentials, access tokens, private account configuration, publishing ledgers or unpublished manuscripts in issues or pull requests. Use environment variables or a private env file for secrets; keep the profile and ledger outside the repository.

If a credential has already been exposed, revoke it with its provider before sharing a sanitized report. This experimental release does not bypass platform verification or authorization requirements. Publish only to accounts you control or are authorized to operate.

安全问题请通过上述邮箱私下反馈，并使用合成资料复现。不要提交 cookie、账号配置、密钥、发布账本或未公开稿件。已经泄露的凭证应先在平台撤销，再提供脱敏后的问题描述。
